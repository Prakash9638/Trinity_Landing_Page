# Trinity Constructions & Interiors — Luxury Architectural Website

A modern, cinematic, and interactive frontend landing page for **Trinity Constructions and Interiors**, serving Hyderabad, Bengaluru, Tirupati, and Kurnool.

## ✨ Core Features & Highlights

- **Strict Brand Color Palette**:
  - Charcoal Black: `#252525`
  - Champagne Gold: `#B69B72`
  - Warm Beige: `#E8DFD0`
  - Ivory White: `#F8F6F1`
  - Pure White: `#FFFFFF`
  *(Zero unauthorized accent colors or default Tailwind palettes).*
- **Cinematic Living Room Transformation Hero**:
  - High-performance HTML5 Canvas animation driven by the 179 sequence frames (`ezgif-frame-001.jpg` to `ezgif-frame-179.jpg`).
  - Interactive scrub slider (Empty Room $\rightarrow$ Fully Furnished Luxury).
  - Autoplay / Loop toggle at 24fps.
  - Scroll-linked sync.
- **Interactive Interior Theme Explorer**:
  - Live interactive showcase of the 5 architectural themes with real 3D renders from `Living room styles`:
    - *Theme 01 – Royal Terracotta & Ochre*
    - *Theme 02 – Moody Emerald & Rich Walnut*
    - *Theme 03 – Organic Ivory & Woven Jute*
    - *Theme 04 – Serene Sage & Pastel Blush*
    - *Theme 05 – Midnight Blue & Polished Platinum*
  - Hover to preview, click to lock, smooth crossfade, and material highlight pills.
- **Editorial Services Showcase**: 6 bespoke services with zoom effects, scope checklists, and category filtering.
- **Six-Step Project Timeline**: Visual process roadmap from initial consultation to final handover.
- **Portfolio & Lightbox**: High-res residential projects with full-screen gallery lightbox.
- **Multi-City Hubs**: Hyderabad, Bengaluru, Tirupati, and Kurnool cards with one-click form prefilling.
- **High-Conversion Consultation Desk**:
  - 10-digit Indian phone number validation (`/^[6-9]\d{9}$/`).
  - One-click WhatsApp message generation directly addressed to `+91 6309255122`.
  - Formatted mailto generator targeting `trinitycon.in@gmail.com`.
- **Floating WhatsApp Desk**: Bottom-right floating quick-action button rendered in the approved Champagne Gold / Charcoal palette.

## 🚀 Running the Project Locally

In your Command Prompt or Terminal, inside `Trinity_Landing_Page`:

1. **Install dependencies**:
   ```cmd
   npm install
   ```

2. **Start the local Vite development server**:
   ```cmd
   npm run dev
   ```

3. Open **`http://localhost:5173/`** in your browser.
